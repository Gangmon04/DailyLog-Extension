DailyLog Documentation & How-To

DailyLog is a developer-focused, offline-first Chrome extension that automatically organizes your daily work by modules (e.g. PMS), auto-syncs with your local journal files (D:\Personal\Data), provides crisp spoken reminders, and generates 1-click standup reports.

Quickstart (30 Seconds)

Get started logging tasks right from your browser toolbar:

  • 1
    Open the Extension: Click the DailyLog leaf icon in your toolbar, or press Alt + Shift + T.
  • 2
    Choose or Type Your Module: Select PMS from the module dropdown, or type directly with prefix e.g. PMS: Compare Dashboard.
  • 3
    Press Enter: The task is instantly created and auto-synced to your local file!
  • 4
    Dock to Sidebar: Click the sidebar icon () in the header to keep DailyLog open beside your code or web apps.

Module Organization (PMS & Custom Modules)

Keep your tasks neatly categorized by project or feature area instead of one big cluttered list.

Custom Module Dropdown

Click the module button right under the input field. A sleek floating menu appears with all registered modules (PMS, etc.).

+ Add Module Inline (No Dialogs)

At the bottom of the module dropdown, type any custom module name in the input box and press Enter. It adds and selects it immediately without native browser popups.

Status Dropdown

Switch between 🟡 In Progress, 🟢 Completed, and 🔴 Blocked with glowing visual indicators.

Smart Prefix Typing (Fastest Method ⚡)

You never need to touch the mouse to change modules. Just type inline:

PMS: Compare Dashboard and Portal for Conflict Appointments
[PMS] Review prescription batch verification

Quick Module Switch: Typing just PMS: and pressing Enter switches the active module dropdown to PMS for all upcoming tasks without creating a blank bullet!

Inline Editing & 1-Click Group Renaming

Everything can be edited in-place with zero disruptive browser popups:

✎ Rename Any Module Header

Click the subtle pencil icon (✎) next to any group title (e.g. "General Tasks"). It turns into an inline text box! Type PMS and hit Enter — every task in that group is instantly renamed and re-synced.

Double-Click Task to Edit

Double-click any task description (or click the edit pencil icon) to edit the text inline. Hit Enter to save, or Escape to cancel.

Automatic Local Folder Sync (D:\Personal\Data)

DailyLog connects directly to your local file system using the modern Chrome File System Access API.

Folder Directory Hierarchy
D:\Personal\Data\YYYY\MM Month\DD-Mon-YYYY.txt

Example: D:\Personal\Data\2026\09 September\21-Sep-2026.txt

How Auto-Sync Works

Every time you add, check off, rename, or delete a task, DailyLog formats it cleanly into your file:

Today's Task:
1. PMS:
- Compare Dashboard and Portal...
Connecting the Folder

Click the folder icon with arrow () in the header. Select your D:\Personal\Data folder once, and permission persists across browser restarts.

Scheduled Reminders & Crispy Voice Notifications

Never forget to plan your morning or wrap up your evening accomplishments.

☀️ Morning Check-In (09:30 AM)

Checks your log at your set morning time. If empty, sends a notification and speaks a short, funny voice prompt to jumpstart your day!

🌙 Evening Wrap-Up (05:30 PM)

Checks pending tasks before you sign off. If all done, congratulates you; if items remain, speaks a crisp nudge to mark them complete.

🎙️ Voice Customization

Supports Chrome Text-to-Speech (TTS) with 12-hour AM/PM pill controls, voice selection (David, Zira, Google English), and speed slider (0.8x–1.5x).

1-Click Standup & Journal Exporters

Located at the bottom of the popup and sidebar for instant sharing:

📋 Copy Standup

Generates clean Markdown formatted for Slack, Teams, or email:

*Completed:*
• Compare Dashboard...

*In Progress:*
• Review PMS batch...
📄 Copy .TXT & Download

Copies the exact plain text format of your journal file, or downloads a .txt file directly to your Downloads folder.

Three Work Surfaces

Work where and how it suits you best:

1. Action Popup

Compact 480×590px window accessible via Alt + Shift + T for rapid 5-second task capture.

2. Persistent Side Panel

Docks directly to the right side of Chrome. Stays open while switching tabs, browsing portals, or coding.

3. Full Dashboard (worklog.html)

Full-screen dashboard with complete calendar history, monthly overview, search filters, and statistics.
