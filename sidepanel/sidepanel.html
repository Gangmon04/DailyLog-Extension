DailyLog Feature Guide

Quick Cheat-Sheet
Quick Add & Tag Enter ↵

Type task and press Enter. Prefix with PMS: Task or [PMS] Task to auto-route into any project module.

Project Modules Dropdown & ✎

Auto-groups tasks by project. Add new modules in dropdown. Click ✎ or double-click header to rename anytime.

Status & Inline Edit Status Dropdown

Pick In Progress, Completed, or Blocked. Click checkbox to mark done. Double-click task to edit in-place.

Local File Auto-Sync D:\Personal\Data

Click folder icon in top-nav. Every task auto-syncs directly into daily YYYY-MM-DD.txt files on your hard drive.

Daily Reminders & Voice Audio TTS

Click bell icon to configure scheduled 9:30 AM & 5:30 PM alerts. Speaks out loud via Chrome Text-to-Speech!

Instant Standup & Export Slack / Teams

Bottom dock icons: copy Slack-formatted daily standup update, copy raw text journal, or download .txt file.

Fullscreen Workspace Full View

Click dashboard icon to open complete full-screen view with calendar history, weekly stats, and scratchpad notes.
